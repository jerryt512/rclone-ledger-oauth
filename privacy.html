隱私權政策 · Privacy Policy

rclone-ledger · 更新日期 Last updated 2026-09-29 · 首頁 Home

存取的資料 · Data accessed

只有在擁有者執行備份時，以 drive.readonly 權限讀取並匯出擁有者指定的那一份 Google 試算表。不讀取其他檔案的內容。

Only when the owner runs a backup, rclone-ledger uses the drive.readonly scope to read and export the one Google spreadsheet the owner specifies. It does not read the content of other files.

使用方式 · How it is used

只用於產生本機備份與檢查備份是否完整。不做分析、廣告，也沒有其他用途。

Solely to create local backups and check their integrity. No analytics, advertising or any other purpose.

儲存 · Storage

匯出的檔案只存在擁有者自己的電腦。rclone-ledger 沒有伺服器，不在任何地方保留副本；備份由擁有者自行保存或刪除。

Exported files stay only on the owner's own computer. rclone-ledger has no server and keeps no copy anywhere; the owner keeps or deletes the backups.

分享與 AI · Sharing and AI

不分享、不出售、不傳送給任何第三方，也不用於訓練或改進任何人工智慧或機器學習模型。

Data is never shared, sold or transferred to any third party, and is never used to train or improve any AI or machine-learning model.

Google API 使用規範 · Google API Services

rclone-ledger 對從 Google API 取得之資訊的使用與傳輸，遵守 Google API Services User Data Policy，包括 Limited Use 規範。

rclone-ledger's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

撤銷授權 · Revoking access

隨時可以到 Google 帳戶的「第三方應用程式與服務」 移除 rclone-ledger 的存取權。

Access can be removed at any time from the third-party apps and services page of the Google Account.
